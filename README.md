# number_guesser

A simple and fun Python game where the user tries to guess a randomly generated number within a given range. The game provides feedback on each guess and tracks the number of attempts.

## ✨ Features
- User-defined upper limit for guessing range
- Random number generation using Python’s `random` module
- Intelligent hints: tells the user to guess higher or lower
- Counts and displays total number of guesses made
